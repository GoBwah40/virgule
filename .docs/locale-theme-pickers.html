Virgule · footer

Language and theme buttons, five options

Each preview reproduces the footer at mobile width. Everything is clickable: the chosen theme applies to the preview (Auto follows your device) and the language changes the labels.

To see how each option copes with Spanish and German.

My recommendation

The single pill (A) if we stay with two languages: it is the current design, calmer, with one outline instead of two; the choices stay visible and dark mode is one tap away. It only needs one new component that groups LocaleToggle and ThemeToggle.

If more languages are planned, the two menus (D): they spell out the language name in full, which helps someone who does not understand the current language, and they keep the same width whatever the number of languages.
